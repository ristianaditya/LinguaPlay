# LinguaPlay

## Register
product

## Users and purpose
Windows PC players who want translated game subtitles, with a game library as the starting point. Choose a game, prepare supported subtitle files, play with translated or original files, or use offline OCR. Existing reference: WeMod/Wand library and in-game controls, supplied by the user.

## Personality
Quiet, confident, focused on the game. Dark player-facing launcher, with compact controls and artwork when available.

## Anti-references
The previous blue-gray form dashboard was rejected by the user. Avoid generic dashboard cards, redundant instructional panels, gradient action buttons, invented game installs, or cheat features suggested by visual references.

## Principles
Game selection before file tools. Explicit original versus translated play. Derive patch state from actual backups. Preserve recovery and offline translation. Show real installed games and truthful empty states.

## Accessibility
Readable text contrast, visible keyboard focus, labeled controls, standard Windows dialogs, no required animation or hover-only actions.
